# [v1.1045](https://github.com/andruwko73/bypass_keenetic/releases/tag/v1.1045) - 2026-09-05

### Применение ключей и нагрузка

- Веб-интерфейс и Telegram-бот используют один безопасный путь применения ключа.
- Повторный выбор уже активного рабочего ключа не перезапускает Xray.
- Проверка применённого ключа идёт через рабочий прокси без отдельного pool worker и временного Xray.
- Один последовательный координатор устраняет наложение фоновых проверок и сохраняет только последнее задание на протокол.
- YouTube prefetch запускается после проверки только для назначенного YouTube-протокола.

### Установка и проверки

- Новый модуль включён в обновление, откат и чистую установку.
- Локально: 310 passed, 1 skipped; UI smoke прошёл в advanced, simple и web_only; secret scan, Python compile и shell syntax прошли.
- GitHub Actions CI run 33962809632 завершён успешно.
