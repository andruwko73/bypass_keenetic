# [1.1007] - 5 авг 2026

### Исправлено

- Автоматическое обновление подписок Vless 1 и Vless 2 больше не блокируется прежним общим порогом RSS 70 МБ: для лёгкого обновления используются отдельные пределы 80 МБ для бота и 110 МБ для всей программы. Лимиты остальных фоновых задач не повышены.
- Ночная полная проверка ключей сначала сохраняется как ожидающая, повторяет запуск каждые пять минут без ограничения числом попыток и не теряется после окончания окна 03:00–06:00 либо перезапуска Telegram-бота.
- Неудачное обновление подписки больше не отменяет ночную проверку: до следующей попытки обновления проверяются уже сохранённые пулы. Временная занятость, нагрузка или пауза оставляют задачу в очереди.

### Производительность и обновление

- Ночная задача использует существующий отдельный worker ручной проверки всех ключей с его ограничителями CPU, памяти и средней нагрузки; новые процессы, демоны и периодические потоки не добавлены.
- Одинаковые причины ожидания записываются в состояние с ограничением частоты, чтобы не создавать лишние операции записи на флешку.
- Миграция меняет только прежнее штатное значение `subscription_auto_refresh_max_bot_rss_kb = 71680`; пользовательские значения сохраняются. Новые настройки добавлены в чистую установку, bootstrap и оба поддерживаемых пути конфигурации.

### Проверено

- 242 Python-регрессии, Ruff `F/E9`, secret scan, Python/JavaScript/Bash syntax и Playwright UI smoke режимов «Сложный», «Простой» и «Только веб».
